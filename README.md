# Virtual-Friend
Do you also need a social life? No problem! Here you go a virtual machine for chatting.

## Steps
1. Download this repository by typing in the terminal: ``git clone "https://github.com/StefiBad/Virtual-Friend"``  
2. Enter inside the directory: ``cd Virtual-Friend``
3. Set your user name in ``username.txt`` file before starting to get a better experience. Change it after typing: ``nano username.txt``
4. Start the conversation: ``./run.sh``

## Features
1. Solve basic math operations
2. Find the current date
3. Play games with you ;D

## Extra
- If step 4 didn't work due to a lack of execution permissions, type: ``chmod +x run.sh`` and repeat the fourth step!
