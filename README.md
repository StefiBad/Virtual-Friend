# Virtual-Friend
Do you also need a social life? No problem! Here you go a virtual machine for chatting.

## Steps
1. Download this repository in the terminal: ``git clone "https://github.com/StefiBad/Virtual-Friend"``  
2. Enter inside the directory: ``cd Virtual-Friend``
3. Start the conversation: ``./run.sh``
4. If step 3 didn't work due to a lack of execution permissions, type: ``chmod +x run.sh`` and repeat the previous step!

## Features
1. Solve basic math operations
2. Find the current date
3. Play games with you :)
4. Change your user name
5. Manage quick notes!
